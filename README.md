# Electric Vehicle (EV) Population Analysis & Insights

## Overview
This repository contains an end-to-end Exploratory Data Analysis (EDA) of the **Electric Vehicle Population Data** sourced from Data.gov. The project analyzes adoption trends, geographic distribution, manufacturer market share, and vehicle specifications across Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).

## Key Objectives
- **Data Preprocessing & Cleaning:** Handle missing values, standardize naming conventions, and structure data types using Python and Pandas in Google Colab.
- **Exploratory Data Analysis (EDA):** Identify key growth trends across registration years, top-performing makes and models, and electric range distributions.
- **Data Visualization:** Build clean, publication-ready visual charts using Matplotlib and Seaborn to communicate complex patterns effectively.

## Tech Stack
- **Language:** Python
- **Environment:** Google Colab 
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
